# UI Direction

## Brand

- Brand: Aptivo muted teal + white.
- Suggested tokens:
  - Primary teal: `#527F7A`
  - Deep teal: `#243B39`
  - Soft background: `#F3F7F6`
  - White: `#FFFFFF`
- Clean education marketplace aesthetic; avoid generic freelance-platform styling.

## Navigation

- **Student navigation:** Home, Explore, My Purchases, My Attempts, Saved.
- **Creator navigation:** Dashboard, Products, Create Product, Analytics, Earnings, Payouts.
- **Admin navigation:** Overview, Users, Creator Applications, Product Review, Orders/Refunds, Payouts, Reports, Settings, Audit.

## Shared components

- Product card
- Creator card
- Verified-claim indicator
- Exam tags
- Price display
- Review card
- MCQ editor
- Status badge
- Modal
- Tables
- Empty states
- Notifications

## Design requirements

- Design desktop and mobile together.
- All controls need meaningful interactions and accessible focus states.
