# MVP Scope

## Include in MVP

- Shared authentication and profiles
- Student and creator permissions
- Creator application and manual verification
- Marketplace home, search, filters, product detail pages
- Product creation for interactive tests and downloadable resources
- Draft/submission/moderation workflow
- Checkout and provider-confirmed payment
- Orders, entitlements, purchase library
- Test attempts, scoring, explanations, results
- Authorized file access
- Creator sales/earnings view
- Admin moderation and transaction support
- Basic reviews, reports, notifications, and audit logs
- Basic analytics for funnel and product performance

## Defer until validation

- Complex subscriptions
- Live classes and community features
- Creator bidding/custom offers
- Automated AI-generated paid tests without human QA
- Advanced recommendation systems
- Multi-tier paid creator subscriptions
- Native mobile apps
- Automated mentorship marketplace (pilot manually first)
- Sophisticated admission-probability predictions without validation

---

## Definition of MVP done

- A student can find a product, pay successfully, and gain the correct access.
- Failed/pending payments never grant unintended access.
- A creator can apply, be approved, publish a reviewed product, and see accurate sales records.
- A creator cannot change another creator's content or financial records.
- A student can take a versioned test and receive correct results and explanations.
- Refunds and payout adjustments reconcile with orders and ledger entries.
- Admin actions are permission-checked and auditable.
- Downloads and answer keys are not publicly exposed.
- Mobile and desktop flows are usable.
- Core metrics are instrumented and the team can reconcile marketplace sales to provider settlements.
